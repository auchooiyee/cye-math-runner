# CYE Math Runner｜CYE 学院 · 数学成长之旅

本方案根据用户提供的五张图片，以及仓库现有的中五 KSSM 数学跑酷系统重新设计。人物名字、性格、学院故事和守护者身份是本次新增的创作设定，并非原图片已经包含的事实。

## 1. 游戏的核心故事

CYE 学院坐落在一座把知识融入日常生活的城市。校园里有钟楼、蓝金色旗帜、巨型书本和数学雕塑；连桥连接不同学习区，湖畔花园留给学生观察与思考，傍晚的创新城区则亮起数学投影。

学院每年举办「Academy Run」。学生沿着八个学习区完成跑酷与数学挑战，在训练守护者的陪伴下积累经验，为最后的 SPM 综合挑战做好准备。

玩家跟随一位热爱跑步的学生，从学院大道出发，逐渐学会把数学用在路线规划、风险判断、公共设施、空间变化和数据分析中。故事的动力是好奇、练习与成长；犯错后可以读懂解释、整理思路，再试一次。

**主旨：Learn. Practice. Run. Grow.**

**一句话介绍：带上你的背包，跑过八个数学街区，把每一次练习变成下一步的信心。**

## 2. 主角：Kai／凯，学院跑者

- **身份**：CYE 学院中五学生，第一次参加完整的 Academy Run。
- **外观依据**：图 1 中的棕色蓬松短发、棕眼、蓝白 CYE 连帽上衣、蓝色背包、深灰条纹运动裤与蓝白运动鞋。
- **性格**：活泼、愿意尝试、喜欢探索捷径，也愿意帮助同学。
- **起点**：反应快、跑得快；遇到复杂题目时也容易急着选答案。他需要练习的是停下来观察条件，分清已知与未知。
- **动机**：想凭自己的努力跑完整条学院路线，让自己对数学更有信心。
- **成长**：从「赶快答完」变成「读懂题目、拆开问题、检查结果」，最终能用学过的方法解决综合问题。
- **背包的意义**：装着练习本、铅笔和记录思路的学习日志，与进度报告的功能形成呼应。
- **玩家代入**：Kai 是默认故事角色；玩家填写自己的跑者昵称，排行榜与进度继续使用原来的昵称系统。
- **口头禅**：「先看清楚，再向前一步。」

### 动作与表情

奔跑时有向前的动力和明亮的表情；换道表现果断；跳跃和滑行突出运动能力。答对时是理解后的开心，答错时是短暂停下思考。护盾耗尽表示本次训练结束，不对应人物受伤或被淘汰。

本次已接入独立的透明背景奔跑、滑行图片。跳跃继续使用奔跑图配合现有物理运动，暂未制作逐帧跑步、跳跃或表情动画。

## 3. 学院与角色关系

**CYE 学院**负责组织课程和跑道训练。图中的皇冠成为学院标志，蓝色代表探索与思考，金色代表投入与成长。

**Crown／皇冠训练系统**负责呈现题目、训练护盾、关卡提醒与章节守护者。它通过可视化挑战帮助学生理解知识，不替学生选择答案。

**八位训练守护者**是同一训练系统的不同教学人格，各自对应原游戏的一章课程。它们与 Kai 是教练和学员的关系，也代表玩家在每章需要学会的一种思考方式。

**其他跑者**由真实参与游戏的学生昵称体现。排行榜记录一次次练习的成果；不额外虚构同学账号或排名。

关系主线：学院提供路线 → Kai 主动尝试 → 守护者提出挑战 → 解释与复习帮助成长 → 最终把八章知识连接起来。

## 5. 八位守护者的人物设计

| 守护者 | 性格与职责 | 与主角的关系／成长提示 |
|---|---|---|
| Ratio Guide 比例向导 | 灵活、善于观察，常追问「如果这个数变了，另一个会怎样？」 | 第一位教练，帮助 Kai 放慢一点、发现关系。 |
| Matrix Navigator 矩阵领航员 | 有条理、耐心，负责把复杂线路整理清楚。 | 教 Kai 按步骤运算，并核对行列位置。 |
| Shield Keeper 护盾守护者 | 稳重、有同理心，重视事前准备。 | 让 Kai 明白勇敢也包括思考风险与后果。 |
| Civic Steward 城市管家 | 公平、务实，关心城市如何一起运作。 | 提醒 Kai 分清不同金额和条件，理解计算的意义。 |
| Prism Architect 棱镜建筑师 | 有创意、喜欢换角度看问题。 | 帮 Kai 建立空间想象，注意变化前后保留了什么。 |
| Wave Conductor 波形指挥家 | 从容、富有节奏感，善于解释周期。 | 教 Kai 找到规律，读准图像与参数。 |
| Data Curator 数据策展人 | 细心、好奇，不急于下结论。 | 提醒 Kai 比较分布与差异，而非只看一个平均数。 |
| Crown Mentor 皇冠导师 | 温和但要求严谨，鼓励解释和检验。 | 最终教练，要求 Kai 把假设、方法、结果与现实联系起来。 |

### 守护者的视觉规则

统一使用蓝白训练终端和金色皇冠，配合各章颜色、环绕数学符号和专属名称。当前版本共享一个友好的终端基础造型；八套独立角色插画属于后续美术扩展，不宣称已经制作。

原有 Boss 的题量、奖励、阶段机制和错误惩罚保持原逻辑；在新设定中它们是训练模拟。HP 代表剩余挑战段落，攻击代表训练压力，护盾代表继续尝试的机会。

## 7. 开场与情绪方向

建议的开场文案：

> 今天，是你参加 CYE 学院挑战的第一天。带好背包，沿着蓝金色旗帜出发吧。前面有八个学习区，也有八位愿意陪你练习的守护者。不用一次就会；看清题目，试着解决，再向前一步。

结束一次训练时，应把注意力放在「这次学会了什么」和「下次可以练哪里」。文案可以有速度感，但避免把错误与聪明程度、自我价值联系起来。
